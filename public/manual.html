Platina32 Song Contest

A complete guide to setting up contestants, entering votes, running reveals, sharing snapshots, checking voting history, exporting results and reusing a finished contest.

01

Before the Contest

Collect the following information for every contestant before you begin:

→
Participant name
The forum username or display name used throughout the voting interface, scoreboard and exports.
→
Represented country
Each contestant represents one country. The setup page prevents the same country from being selected twice.
→
Artist and song title
These appear on the live scoreboard, final standings, shared pages and spreadsheet exports.
Important: Give every participant a unique display name. The app uses participant names throughout the voting order, reveal and voting-history matrix.
Tip: Publish the complete song list before voting begins so participants have time to listen and prepare their votes.
02

Setting Up the Contest

Open the Song Contest app from platina32.com. The setup page is where you create the contest, choose its scoring system and enter all contestants.

1
Enter the contest title
The title appears above the scoreboard and is used in shared pages and exported filenames. Example: MU Worldvision Song Contest 47
2
Choose a scoring system
Select Eurovision (12-10-8-7-6-5-4-3-2-1), Formula 1 (25-18-15-12-10-8-6-4-2-1), or Custom.
3
Configure custom points, when used
Enter how many scoring positions are required, press ✓, and enter a positive point value for each position. Up to twenty scoring positions can be created.
4
Add each contestant
Select the country, enter the participant name, artist and song, then click Add Contestant. Countries already in use are disabled.
5
Edit or remove entries
Use ✏️ to edit an entry and ✕ to remove it before the contest begins.
6
Choose the voting order
Drag contestants with the ⠿ handle, use Sort A–Z to sort by represented country, or Shuffle for a random order. The displayed setup order becomes the voting order after the contest starts.
7
Start the contest
Click Start Contest. The button becomes available when all custom points are filled and there are enough contestants.
Minimum size: A contest needs at least one more contestant than the number of scoring positions, because nobody may vote for themselves. Eurovision scoring has ten positions, so it requires at least eleven contestants.
03

Running the Voting Rounds

The voter bar and voting panel show whose turn it is. Each contestant submits exactly one round.

1
Enter the current voter's points
Use one dropdown for each point value. The current voter is disabled and cannot vote for themselves.
2
Complete every scoring position
Every point value must be assigned, and a recipient may not receive two different point values from the same voter. The progress bar and counter show how many choices are complete.
3
Submit the round
Click Submit Votes ✦. The app records the round, updates the true standings and advances to the next voter.
4
Correct the most recent round when necessary
Click ↩ Undo Last Round to remove the most recently submitted voter's points, clear that row from the voting history and return the voting panel to that same voter. Re-enter and submit the corrected round.
5
Continue until everybody has voted
The header shows the current round and total number of rounds. A voter cannot submit a second recorded round unless their previous round has first been undone.

Reading the live scoreboard

Automatic ranking Contestants are ranked by total points as rounds are submitted and revealed.
Tiebreaking Equal totals are separated by the number of highest scores received, comparing point values from highest to lowest.
Maximum-score marker The ★ column shows how often a contestant received the highest available point value. Hover over its marker to see which voters awarded it.
Reveal highlights During a reveal, the current voter, already-finished voters and recipients of revealed points receive different row highlights.
04

Reveals and Snapshot Links

Reveal on the host screen

After submitting a round, click ▶ Show Reveal. The scoreboard returns to its pre-round state, allowing you to reveal the submitted scores one at a time.

  • Click Next → for each award.
  • The recipient's score and ranking animate after each reveal.
  • Click Done ✓ after the final award.
  • The reveal can be opened again; it restarts from the same pre-round standings.

Share an individual voting round

Click 🔗 Generate Snapshot Link after a round has been submitted. A new read-only page opens for that voting round.

  • Every viewer controls their own reveal independently.
  • Viewers can reveal manually or use autoplay.
  • The shared page begins from the standings before that voter's points were added.
  • Its Export button downloads the scoreboard state displayed on that snapshot page.
Snapshot behaviour: A generated link is a saved copy. It does not change when the host later undoes or edits local contest data. Generate a new link when you need an updated copy.
05

Organiser Voting History and Exports

Organiser Voting History

Open the collapsible 📋 Organiser Voting History section underneath the live rankings. It provides a full voter-by-recipient matrix.

Rows are voters Each completed row shows every point value awarded by that voter.
Columns are recipients Read down a column to see every score received by one contestant.
Awarded total The final cell in each completed row shows the total points distributed by that voter.
Received total The footer total beneath each recipient should match that contestant's scoreboard points.

For large contests, the matrix scrolls horizontally and vertically. The voter column and recipient headings remain visible while scrolling.

Spreadsheet exports

Export location Workbook contents Purpose
Live scoreboard 📊 Export Standings + Voting History Save the current contest state during voting.
Current final-results screen Results + Voting History Download the complete finished contest.
Previously saved contest Results + Voting History Export the saved contest later from the setup page.
Shared final-results page Standings + Voting History Allow anyone with the final link to download the complete overview.
Shared round-reveal page Standings Export the scoreboard displayed for that individual round.
Consistency check: At the end of the contest, each contestant's scoreboard total, the Received footer in the voting matrix and the exported total should all be identical.
06

Ending and Sharing the Contest

1
Finish the final voting round
After the last voter submits, complete the reveal or verify the standings. The 🏆 End Contest & Show Results button is available for the host.
2
Confirm the contest ending
The app asks for confirmation, then opens the final-results screen with a top-three podium and complete standings.
3
Save results locally
Click 💾 Save Results to make the finished contest available later from the app's setup page.
4
Share the final results
Click 🔗 Share Final Results. The shared page displays the podium and standings, and its Export button includes the complete voting history.
5
Export the workbook
Click 📊 Export to Spreadsheet to download the final rankings and voter-by-recipient history.
6
Return to setup
Use ← Back to Setup when you are finished. Save the results first when you want the contest to remain available in the app.
07

Saved and Previous Contests

Resume an unfinished contest

The app automatically saves active contest state in the browser. When the setup page detects one, it displays a resume banner.

  • Resume Contest restores contestants, standings, voting order, history and the most recent round state.
  • Discard & Start Fresh removes the saved active contest.

Open a finished contest

After using 💾 Save Results, the setup page shows 📋 View Previously Finished Contest. From this screen you can:

  • review the podium and final standings;
  • export the saved results and voting history;
  • generate a new shareable final-results link;
  • reuse the same participant list for a new contest.

Reuse participants

Reusing a previous contest copies participant names, countries, artists and songs back into setup, while resetting all points, score counts, maximum-score records and voting history.

Previous contest history: Voting history is available only for contests saved after the voting-history feature was added. Older saved contests may contain final standings without the detailed matrix.
08

Storage, Recovery and Practical Notes

What is stored locally?

Contest setup, active progress, Undo data, voting history and explicitly saved finished results use the browser's local storage. Ordinary vote submission does not create a database write.

What is stored online?

A cloud snapshot is created only when the host deliberately generates a round link or final-results link. The final-results snapshot contains the standings and voting matrix needed for its export.

Browser-specific storage: Local saves belong to the browser and device on which they were created. Clearing site data, using another browser or switching devices will not carry those local saves across automatically.

Recommended host routine

  • Use unique participant names.
  • Check the current voter before every submission.
  • Use Undo immediately when the latest round is wrong.
  • Compare voting-history Received totals with the scoreboard before ending.
  • Save the finished contest before returning to setup.
  • Download the final spreadsheet as a permanent offline record.
  • Test shared links in a private/incognito window before distributing them.
